# UK Castles website

The website for the UK Castles Android app: what it is, its privacy policy,
the open data downloads and the contact form. Published with GitHub Pages at
https://urawizard.github.io/castle-app-site/

These files are generated: they are built from the app's main repository
(`site/build_site.py`) and copied here. Change them there, not here.

Wikipedia (CC BY-SA 4.0); see data.html.
