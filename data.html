Open data

The castle data in the app is free to download and reuse. It is built on OpenStreetMap, Wikidata and Wikipedia, and these files share it back on the same terms.

castles.json (2.9 MB) 3,887 castles: names, positions, types, build period, what remains (checked by hand), and the visiting information (who runs it, ticket page, or not open to the public, with evidence-based checks). Open Database Licence (ODbL) 1.0

The map

The app's offline map is made from the Protomaps basemap daily build of OpenStreetMap data (also ODbL), cut to the United Kingdom, limited to zoom level 12, and with land uses and map icons that the app does not draw removed (farmland, meadows, residential areas, gardens, pitches, wetlands, farmyards, and all point-of-interest icons). Anyone can make the same file from the public Protomaps build in this way. To ask for a copy of the file itself, use the contact form.
